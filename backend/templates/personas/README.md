# Справочные шаблоны скилов

Файлы в этой папке **не копируются** в проект автоматически.

Создайте скил через **«Добавить»** в чате CoreX  
или скопируйте `.md` в `chat/personas/` открытого проекта.

Формат:

```markdown
---
id: developer
name: Разработчик
description: Senior-разработчик
category: development
---

Текст промпта — как должен вести себя AI.
```

Подробнее: `docs/SKILLS.md`
