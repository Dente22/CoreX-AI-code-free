# Инструкция: обновить CoreX дома с GitHub

Репозиторий: https://github.com/Dente22/CoreX-AI-code-free

## Если папка уже есть (`D:\Project\CoreX`)

```bat
cd /d D:\Project\CoreX
git pull origin main
scripts\ensure_aider_venv.bat
start-corex.bat
```

Модель: `ollama pull qwen2.5-coder:7b`

Дальше читай **`ДОМА-22-09-2026.md`**.

## Если клонируешь заново

```bat
cd /d D:\Project
git clone https://github.com/Dente22/CoreX-AI-code-free.git CoreX
cd CoreX
scripts\ensure_aider_venv.bat
start-corex.bat
```

Первый запуск долго ставит `.venv` и `npm install`.

## Что не копировать / не коммитить

- `models/`, `ollama_models/` (веса)
- `.venv/`, `.venv-aider/` (ставятся скриптами)
- `.env`, ключи в `%LOCALAPPDATA%\CoreX\secrets\`

## Переключатель движка

Чат → Оркестрация → **Aider** | **CoreX**.  
Для кода по умолчанию Aider.

## Если Aider ругается

1. Есть ли `D:\Project\CoreX\.venv-aider\Scripts\aider.exe`?
2. Если нет — `scripts\ensure_aider_venv.bat` (нужен Python 3.11 или 3.12).
3. Ollama запущена, модель в настройках CoreX выбрана.
